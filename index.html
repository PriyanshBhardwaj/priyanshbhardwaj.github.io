01 - Featured · GitHub App

GARRICK
Multi-Agent PR Intelligence

A GitHub App that reviews pull requests with a multi-agent pipeline and Graph RAG — line-level feedback that understands the repository, not only the diff. Call structure is mapped first so a change is scored by how it propagates. Orchestration is LangGraph; tools (graph queries, file reads, GitHub comments) sit on an MCP server so agents share one schema.

Specialist agents run in parallel over that graph — security, quality, coverage, cross-file impact — then a validation step filters findings before they are posted.

Architecture Decisions That Mattered
LangGraph orchestration
Map → specialist agents → validate → comment. Independent checks run as parallel branches; graph state holds the repo map and candidate findings.
MCP tool server
Graph lookup, file read, and GitHub comment posting are MCP tools. Agents bind them at runtime instead of each carrying its own copy.
Repository graph before review
Call structure and dependency edges are mapped first. Review starts with blast radius, not an isolated file diff.
Validated findings
A separate check runs before anything is posted, so hallucinated issues are dropped rather than adding comment noise.
Polyglot structural parsing
Python, JavaScript, TypeScript, Go, Java and more via structural parsing, so the graph is not limited to one language.
